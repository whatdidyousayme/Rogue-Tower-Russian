# Rogue Tower Russian 1.2

Русская локализация Steam-версии Rogue Tower 1.3.2.0 (App ID 1843760), Windows, Unity Mono x86.

## Установка

1. Скачайте архив **Translate Rogue Tower v 1.2.zip** со страницы [последнего релиза](https://github.com/whatdidyousayme/Rogue-Tower-Russian/releases/latest).
2. Распакуйте архив и закройте игру. Для обновления предыдущей версии удалять мод не нужно.
3. Запустите `RogueTowerRussian_Installer.exe`.
4. Выберите папку с `Rogue Tower.exe` и нажмите **«Установить мод»**.
5. Запустите игру через Steam.

Установщик автономный: BepInEx 5.4.23.3 x86, DLL плагина, словарь и исходники встроены в один EXE. Интернет и соседние файлы для установки не нужны. Неполная установка BepInEx восстанавливается автоматически. Установка проверяет разрядность, целостность архива и скопированных файлов. При ошибке копирования заменённые файлы восстанавливаются из резервной копии.

## Перевод

Перевод охватывает меню, улучшения, карточки, бестиарий, имена противников и боссов, подсказки, характеристики, статистику и надписи в мире. Словарь сверяется с текстами сборки 1.3.2.0. Тексты из интерфейса Unity, TextMeshPro и TextMesh обрабатываются при изменении и резервным обходом каждые 0,5 секунды. Числа в составных строках сохраняются, теги форматирования не переводятся.

Кнопка **«Перевод: ВКЛ/ВЫКЛ»** находится справа вверху. Настройка сохраняется в `BepInEx/config/com.rogueTower.russian.cfg`. При отключении возвращаются актуальные английские тексты, включая карточки, которые игра использует повторно. Под кнопкой расположен ползунок **«Масштаб текста»** (50–140%, по умолчанию 100%). Значение сохраняется между запусками. Размер дополнительно ограничивается свободным местом: длинные заголовки уменьшаются, описания сохраняют переносы, столбцы статистики используют общий размер и шаг строк. При отключении перевода восстанавливается исходное оформление.

Текст в мире использует материал с проверкой глубины. Письмо под стартовым участком ограничено областью с переносами строк, чтобы не вытягиваться за край земли.

Словарь: `BepInEx/plugins/translations.json`. Его можно редактировать; изменения вступают в силу после перезапуска игры. **«Восстановить словарь»** возвращает словарь установщика и сохраняет текущую копию.

Возможные непереведённые строки автоматически записываются в `BepInEx/config/RogueTowerRussian.untranslated.jsonl`. Это позволяет проверять редкие игровые ситуации. Бренд Rogue Tower, обозначения клавиш и римские номера улучшений могут оставаться латиницей. Знаки `???` в закрытых записях бестиария задаёт сама игра.

## Резервные копии и удаление

Резервные копии лежат в `RogueTowerRussian_backups`, вне дерева плагинов. Старые копии из `BepInEx/plugins/_backup` переносятся туда, чтобы BepInEx не загружал DLL перевода второй раз.

**«Удалить мод»** удаляет DLL переводчика и словарь. BepInEx, другие моды, исходники и резервные копии сохраняются. Перед установкой или удалением закройте игру. Файлы самой игры и сохранения не изменяются установщиком.

## Сборка

Нужны Python 3.11+, PyInstaller и установленная игра. Компилятор .NET Framework берётся из Windows. Архив `bepinex_core.zip` должен лежать в корне проекта; требуется полный пакет BepInEx 5.4.23.3 для Windows x86.

Скачайте [BepInEx 5.4.23.3 x86](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.3/BepInEx_win_x86_5.4.23.3.zip) и сохраните его как `bepinex_core.zip` без распаковки. Установите зависимости: `python -m pip install pyinstaller`. Путь к игре можно передать через `--game` или переменную `ROGUE_TOWER_DIR`.

```powershell
python build_mod32.py --game "E:\SteamLibrary\steamapps\common\Rogue Tower"
python mod_installer/build_installer.py --game "E:\SteamLibrary\steamapps\common\Rogue Tower"
```

DLL создаётся в `build/RogueTowerRussian.dll`, EXE — в `mod_installer/dist`. Сборка не устанавливает мод в игру. Пакет формируется из исходников этого проекта, поэтому состояние папки игры не влияет на комплектность установщика.

## Проверки для разработчика

```powershell
python tools/test_installer.py
python tools/audit_translations.py
```

Первый скрипт проверяет чистую установку, повторную установку, восстановление неполного BepInEx, ошибочный комплект, разрядность и откат после сбоя. Второй извлекает текстовые кандидаты из Assembly-CSharp и сериализованных ресурсов игры (нужен UnityPy). Кандидаты включают внутренние имена объектов и методов: их наличие в отчёте само по себе не означает пропуск в интерфейсе. `tools/CheckTranslations.cs` проверяет тот же движок перевода без Unity, включая динамические числа и rich text.

Клавиша F9 сохраняет диагностический отчёт размеров активных надписей в `BepInEx/config/RogueTowerRussian.layout.json`. Измерения выполняются одним размером шрифта, чтобы не переполнять динамический атлас Unity.
